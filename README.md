## 双ISP 到底是什么：一个 IP 挂两个 ISP，不是给你两个 IP

双 ISP 指同一个 IP 在两个不同民用宽带运营商名下都有注册记录，比如美国的 Comcast 加 Charter、香港的 iCable 加 HGC。平台查 IP 时会看 ASN 归属，机房段一眼就是机房流量，家宽段在数据库里和普通住户没区别。两个 ISP 的意义在于容错：一个段被批量标记，另一个还留着。

**双 ISP 不等于两个 IP。** 它说的是同一个 IP 的注册记录，不是分配两个不同地址。WePC 这些套餐同样只给 1 个独立 IPv4，需要多 IP 得另想办法。

顺带把另外两个常混的概念分清：

- 原生 IP：IP 注册地和机房物理位置一致，解决的是"归属地对不对"。
- 住宅 IP：ASN 归属是民用宽带运营商，解决的是"像不像真人"。
- 双 ISP：在住宅 IP 基础上再加一层 ISP 冗余。

三个都满足，才是一台能直接绑号的机器。买之前对着商品描述逐条看，只写"原生"两个字的，大概率只满足了第一条。

## 拿到机器先别绑号：三步验 IP

WePC 官网页面上专门写了一行"ip查询"，说明它自己也知道买家会验。顺序是这样：

1. 用 ipinfo 查 ASN，看归属公司是民用宽带运营商还是 IDC 服务商。
2. 用 IP2Location 查 usage type，家宽一般显示 ISP 或 MOB，机房显示 DCH。
3. 用 Scamalytics 看风险评分，分数越低越好。

三项都对得上，再去绑号。归属地和你买的地区不一致、usage type 显示 DCH、风险分很高，任意一条不符就趁退款窗口提工单，别先上了号再回头找。
